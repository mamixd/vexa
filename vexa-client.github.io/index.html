Kurulum

İndir, kur, launcher üzerinden oyunu başlat.

  1. Setup dosyasını indir.Buton her zaman GitHub’daki en son release dosyasını bulur.
  2. Kurulumu çalıştır.Windows uyarı verirse yayıncı imzası nedeniyle olabilir.
  3. Launcher’dan devam et.Güncelleme geldiğinde launcher yeni paketi otomatik kontrol eder.

Windows uyarısı görürsen

Vexa bağımsız bir topluluk projesi olduğu için bazı Windows kurulumlarında bilinmeyen yayıncı uyarısı çıkabilir. Dosyalar GitHub release üzerinden yayınlanır; güncel sürümü her zaman bu sayfadaki otomatik indirme butonundan al.
